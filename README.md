# 總舖師傳奇（`pg-empirekitchen`）

灶腳餐廳經營：班次內排菜出餐、班次外研發菜色、雇傭員工、升級廚房，達標後展店獲勝。

## 遊玩

純 HTML／CSS／JavaScript（無 build）。在 Playgrounds 畫布或 go 純玩模式開啟。

- **班次**：點訂單排菜 → 出爐後再點出餐；注意客人耐心。
- **店務**：研發、雇人、升級、開班。
- **勝利**：資金／名聲／菜色／天數達標後「展店」。
- **失敗**：破產或名聲歸零。

## 開發

```bash
npx vitest run
```
